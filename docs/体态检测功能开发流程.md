## 📋 项目概述

### 功能目标
开发一个完整的静态体态检测系统，用于用户的体态健康评估，包括多角度拍照引导、AI体态分析、评分反馈和历史趋势追踪。

### 核心特性
- **多角度检测**：正面 + 左侧面 + 右侧面 + 背面（4个完整角度）
- **AI智能分析**：基于YOLOv8 Pose的17个关键点检测，计算体态指标
- **综合评分**：0-100分评分系统，包含基础体态、常见问题、详细角度分析
- **智能反馈**：具体问题描述 + AI改善建议 + 可视化对比
- **历史追踪**：保存至少两学年的检测记录，支持趋势分析
- **功能整合**：与现有动作评分系统结合，影响评分权重

### 应用场景
- 学生上课前体检
- 定期健康监测
- 具体训练前的基准评估

## 🗂️ 需求规格

### 1. 功能需求

#### 1.1 检测范围
- **基础体态**：身体是否站直、左右对称
- **常见体态问题**：
  - 圆肩（肩膀向内扣）
  - 头前伸（头部过度前倾）
  - 驼背（胸椎过度后凸）
  - 骨盆前倾（腰椎过度前凸）
  - 脊柱侧弯（脊柱侧方弯曲）
  - 高低肩（左右肩不对称）
- **详细评估**：具体角度数值计算

#### 1.2 评估结果
- **综合评分**：0-100分体态评分
- **具体描述**：检测到的体态问题描述
- **AI建议**：针对性的改善建议
- **可视化对比**：标准体态与当前体态对比图

#### 1.3 检测角度
- 正面（front）：检测左右对称性
- 左侧面（left_side）：检测脊柱和颈部曲线
- 右侧面（right_side）：侧面验证
- 背面（back）：检测脊柱对称性

#### 1.4 与现有功能整合
- **独立模块**：体态检测作为独立功能模块
- **动作评分配合**：体态数据影响动作评分权重
- **基准评估**：训练前的体态基准检测

#### 1.5 数据精度
- **优先选择**：3D体态重建（基于多角度照片）
- **备选方案**：基于关键点的角度计算
- **数据留存**：保存至少两学年

### 2. 技术需求

#### 2.1 性能要求
- 拍照识别响应时间 < 3秒
- 4角度总检测时间 < 30秒
- 系统支持并发用户数 >= 50

#### 2.2 准确度要求
- 关键点检测置信度 > 0.7
- 体态问题检测准确率 > 85%

#### 2.3 兼容性要求
- 支持主流浏览器（Chrome、Firefox、Edge）
- 支持移动端和桌面端
- 支持不同分辨率摄像头

### 3. 关键算法实现

#### 3.1 身体平衡度计算

```python
def calculate_balance_metric(front_keypoints) -> float:
    """
    计算身体平衡度

    Args:
        front_keypoints: 正面角度的关键点数据

    Returns:
        平衡度评分 (0-100)
    """
    # 获取关键点对
    left_shoulder = front_keypoints.get('left_shoulder')
    right_shoulder = front_keypoints.get('right_shoulder')
    left_hip = front_keypoints.get('left_hip')
    right_hip = front_keypoints.get('right_hip')
    left_knee = front_keypoints.get('left_knee')
    right_knee = front_keypoints.get('right_knee')
    left_ankle = front_keypoints.get('left_ankle')
    right_ankle = front_keypoints.get('right_ankle')

    # 计算各关键点对的对称性偏差
    shoulder_deviation = abs(left_shoulder[0] - (1 - right_shoulder[0]))
    hip_deviation = abs(left_hip[0] - (1 - right_hip[0]))
    knee_deviation = abs(left_knee[0] - (1 - right_knee[0]))
    ankle_deviation = abs(left_ankle[0] - (1 - right_ankle[0]))

    # 综合计算平衡度
    total_deviation = (shoulder_deviation + hip_deviation +
                      knee_deviation + ankle_deviation) / 4

    # 将偏差转换为评分：偏差越小评分越高
    balance_score = max(0, min(100, 100 - total_deviation * 200))

    return round(balance_score, 2)
```

#### 3.2 脊柱对齐度计算

```python
def calculate_spinal_alignment(side_keypoints) -> float:
    """
    计算脊柱对齐度（侧面视角）

    Args:
        side_keypoints: 侧面角度的关键点数据

    Returns:
        脊柱对齐度评分 (0-100)
    """
    # 获取侧面关键点
    ear = side_keypoints.get('left_ear') or side_keypoints.get('right_ear')
    shoulder = side_keypoints.get('left_shoulder') or side_keypoints.get('right_shoulder')
    hip = side_keypoints.get('left_hip') or side_keypoints.get('right_hip')
    knee = side_keypoints.get('left_knee') or side_keypoints.get('right_knee')
    ankle = side_keypoints.get('left_ankle') or side_keypoints.get('right_ankle')

    # 计算脊柱曲线：耳-肩-髋-膝-踝应该在一条垂直线上
    # 使用最小二乘法拟合直线
    points = [(ear[0], ear[1]), (shoulder[0], shoulder[1]),
              (hip[0], hip[1]), (knee[0], knee[1]), (ankle[0], ankle[1])]

    # 计算各点到理想垂直线的偏离程度
    center_x = sum(p[0] for p in points) / len(points)
    deviations = [abs(p[0] - center_x) for p in points]
    max_deviation = max(deviations) if deviations else 0

    # 偏离越小，脊柱越直，评分越高
    alignment_score = max(0, min(100, 100 - max_deviation * 300))

    return round(alignment_score, 2)
```

```python
            'severity': round_shoulders['severity'],
            'value': round_shoulders['angle'],
            'threshold': round_shoulders['threshold']
        })

    # 2. 检测头前伸
    forward_head = detect_forward_head(side_kp)
    if forward_head['detected']:
        issues.append({
            'code': 'forward_head',
            'severity': forward_head['severity'],
            'value': forward_head['ratio'],
            'threshold': forward_head['threshold']
        })

    # 3. 检测驼背
    kyphosis = detect_kyphosis(side_kp)
    if kyphosis['detected']:
        issues.append({
            'code': 'kyphosis',
            'severity': kyphosis['severity'],
            'value': kyphosis['curvature'],
            'threshold': kyphosis['threshold']
        })

    # 4. 检测骨盆前倾
    lordosis = detect_lordosis(side_kp)
    if lordosis['detected']:
        issues.append({
            'code': 'lordosis',
            'severity': lordosis['severity'],
            'value': lordosis['angle'],
            'threshold': lordosis['threshold']
        })

    # 5. 检测脊柱侧弯
    scoliosis = detect_scoliosis(front_kp, keypoints.get('back', {}))
    if scoliosis['detected']:
        issues.append({
            'code': 'scoliosis',
            'severity': scoliosis['severity'],
            'value': scoliosis['curvature'],
            'threshold': scoliosis['threshold']
        })

    # 6. 检测高低肩
    uneven_shoulders = detect_uneven_shoulders(front_kp)
    if uneven_shoulders['detected']:
        issues.append({
            'code': 'uneven_shoulders',
            'severity': uneven_shoulders['severity'],
            'value': uneven_shoulders['difference'],
            'threshold': uneven_shoulders['threshold']
        })

    return issues
```

### 5. 评分引擎设计

```python
# services/posture_scoring_service.py

class PostureScoringEngine:
    """体态评分引擎"""

    def __init__(self):
        self.issue_weights = {
            'round_shoulders': 15,
            'forward_head': 20,
            'kyphosis': 25,
            'lordosis': 20,
            'scoliosis': 30,
            'uneven_shoulders': 10
        }

    def calculate_overall_score(self, metrics: Dict, issues: List) -> Dict:
        """
        计算综合体态评分

        Args:
            metrics: 体态各项指标
            issues: 检测到的体态问题列表

        Returns:
            {
                'overall_score': 总分,
                'metric_scores': 各指标评分,
                'issue_scores': 各问题扣分
            }
        """
        # 1. 基础指标评分
        metric_scores = self._calculate_metric_scores(metrics)

        # 2. 问题扣分计算
        issue_scores = self._calculate_issue_scores(issues)

        # 3. 综合评分计算
        base_score = sum(metric_scores.values()) / len(metric_scores) if metric_scores else 80
        issue_deduction = sum(issue_scores.values())
        overall_score = max(0, min(100, base_score - issue_deduction))

        return {
            'overall_score': round(overall_score, 2),
            'metric_scores': metric_scores,
            'issue_scores': issue_scores,
            'issues_count': len(issues),
            'severe_issues_count': len([i for i in issues if i['severity'] == 'severe'])
        }

    def _calculate_metric_scores(self, metrics: Dict) -> Dict:
        """计算各项指标的评分"""
        scores = {}

        # 根据指标的不同权重和阈值进行评分
        for metric_name, metric_value in metrics.items():
            if metric_value is not None:
                score = self._score_metric(metric_name, metric_value)
                scores[metric_name] = score

        return scores

    def _calculate_issue_scores(self, issues: List) -> Dict:
        """计算体态问题的扣分"""
        scores = {}

        for issue in issues:
            issue_code = issue['code']
            severity = issue['severity']

            # 根据严重程度计算扣分
            severity_multiplier = {
                'none': 0,
                'mild': 0.3,
                'moderate': 0.6,
                'severe': 1.0
            }

            base_deduction = self.issue_weights.get(issue_code, 10)
            actual_deduction = base_deduction * severity_multiplier.get(severity, 0.5)

            scores[issue_code] = round(actual_deduction, 2)

        return scores
```

```python
# 在score_service.py中添加体态影响逻辑

class ScoreCalculator:
    def __init__(self):
        self.posture_adjustment_enabled = True

    def apply_posture_adjustment(self, base_score: float, user_posture_score: float, action_difficulty: float) -> float:
        """
        根据体态状况调整动作评分

        Args:
            base_score: 基于动作完成的原始评分
            user_posture_score: 用户体态评分
            action_difficulty: 动作难度系数（动作对身体稳定性的要求）

        Returns:
            调整后的评分
        """
        if not self.posture_adjustment_enabled:
            return base_score

        # 体态良好的用户，评分不受影响
        if user_posture_score >= 85:
            return base_score

        # 体态较差的用户，根据动作类型给予适当宽容度
        # 身体稳定性要求高的动作（如平衡类动作）受体态影响更大
        if action_difficulty > 0.8:  # 高难度动作
            adjustment_factor = 1 + (100 - user_posture_score) * 0.0015
        elif action_difficulty > 0.5:  # 中等难度动作
            adjustment_factor = 1 + (100 - user_posture_score) * 0.001
        else:  # 基础动作
            adjustment_factor = 1 + (100 - user_posture_score) * 0.0005

        adjusted_score = min(100, base_score * adjustment_factor)
        return round(adjusted_score, 2)

    def get_posture_impact_note(self, user_posture_score: float, action_difficulty: float) -> str:
        """生成体态影响说明"""
        if user_posture_score >= 85:
            return "体态良好，动作评分未受影响"

        if user_postpose_score >= 70:
            return "体态存在轻微问题，对高难度动作评分有一定影响"
        else:
            return "建议先改善体态后再进行此类动作练习"
```

```python
# 添加复合分析功能

class IntegratedAnalysis:
    def analyze_progress_trends(self, user_id: int, time_period: str) -> Dict:
        """
        综合分析用户的体态和动作训练进展趋势

        Returns:
            {
                'posture_trend': 体态趋势数据,
                'action_scores_trend': 动作评分趋势,

        action_data = self.get_score_history(user_id, time_period)

        # 分析体态改善与动作评分提升的相关性
        correlation = self.calculate_correlation(
            posture_data.scores,
            action_data.scores

            'action_scores_trend': action_data.trend,
```

## 🚀 部署方案

- 数据库: MySQL 8.0
- 后端: Python 3.10+ + uvicorn --reload
- 前端: npm run dev
- AI模型: YOLOv8n-pose.pt (CPU模式)

### 生产环境
- 数据库: MySQL 8.0 + 主从复制
- 后端: Gunicorn + Uvicorn workers (4-8进程)
- 前端: Vite build + Nginx
- AI模型: YOLOv8s-pose.pt (GPU加速)
- 文件存储: 对象存储服务 (如阿里云OSS)
