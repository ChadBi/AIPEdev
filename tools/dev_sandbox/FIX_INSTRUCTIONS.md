# 体态检测功能调试指南

## 当前状态确认

## 如果前端页面卡住，请按以下步骤操作：

### 1. 强制刷新页面
- 按 `Ctrl + Shift + R` (Chrome/Edge) 或 `Cmd + Shift + R` (Mac) 强制刷新
- 清除浏览器缓存

### 2. 检查浏览器控制台
- 按 `F12` 打开开发者工具
- 查看 "Console" 标签页
- 查看新增的详细调试信息

### 3. 检查网络请求
- 按 `F12` 打开开发者工具
- 切换到 "Network" 标签页
- 查找 `/posture/assess` 请求
- 检查请求状态和响应

### 4. 重新测试流程
1. 访问 http://localhost:3003
2. 登录 (admin/admin123)
3. 进入体态检测页面
4. 按照4个角度依次拍照：
   - 正面
   - 左侧面
   - 右侧面
   - 背面
5. 点击"开始分析"按钮
6. 查看调试信息显示

## 预期行为
- 每张照片拍完后，会自动跳转到下一个角度
- 4张照片拍完后，会自动进入分析状态
- 显示进度条："准备数据" → "上传照片" → "分析完成"
- 最终显示体态评分结果

## 如果仍然卡住
1. 查看浏览器控制台中的详细日志
2. 查看网络请求的状态和错误信息
3. 检查是否所有照片都已正确拍摄
4. 检查网络连接是否正常

## 后端服务管理
- 启动: `uv run uvicorn main:app --host 0.0.0.0 --port 9999 --reload`
- 停止: `taskkill //F //IM python.exe`
- 日志位置: `AIPEdev/server_new.log`

## 前端服务管理
- 启动: 进入 `front` 目录，运行 `npm run dev`
- 当前前端端口: http://localhost:3003
- 静态资源CDN警告可以忽略（开发环境）

## 常见问题
1. **摄像头权限**: 确保浏览器允许摄像头访问
2. **网络连接**: 检查后端服务是否运行在9999端口
3. **文件大小**: 确保照片文件大小合理
4. **浏览器兼容性**: 建议使用Chrome或Edge最新版本
